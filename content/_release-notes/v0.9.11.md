## Version 0.9.11

March 8, 2026

- Added `folders_in_folder(folder)` that returns a 
non-recursive list of folders inside the folder at the 
given path. 

- Added `files_in_folder(folder)` that returns a 
non-recursive list of the files inside the folder at the 
given path. 

- Added `files_in_folder_with_extension(folder, extension)` that returns a 
non-recursive list of the files with the given 
extension inside the folder at the 
given path.
